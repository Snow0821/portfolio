# 한글 렌즈

시험지 사진을 브라우저 안에서 읽고, 검토·수정하여 한글 HWPX로 저장하는 정적 웹 앱입니다. 기존 포트폴리오에 `/ocr/` 경로로 추가됩니다.

## 사용

1. JPG, PNG, WEBP 사진을 추가합니다. 최대 20장, 사진당 25MB입니다.
2. 사진 순서와 방향, 1단/2단 읽기 순서를 확인합니다.
3. 그래프·가계도 등은 **그림 영역 지정**을 눌러 양 끝을 선택하고 **그림 추가**로 보존합니다.
4. **전체 사진 읽기**를 누릅니다. 최초 실행 시 한국어·영어 모델을 다운로드하며, 인식 시간은 기기와 사진 크기에 따라 달라집니다.
5. 원본과 대조해 글자를 수정하고 블록 종류를 문제·문단·보기 표·선지로 지정합니다. 블록과 사진의 순서를 바꿀 수 있습니다.
6. **HWPX 다운로드**로 저장합니다. **작업 저장**은 원본 사진과 편집 상태를 JSON 파일로 보관하며 **작업 불러오기**로 복원합니다.

## 범위와 한계

- OCR: Tesseract.js 7.0.0 / Tesseract LSTM, `kor+eng`, WebAssembly + Web Worker. 각 단을 따로 읽고, 회색조·명암·붉은 필기 완화를 적용합니다. 이미지 크기는 긴 변 3,000px 이내로 조정합니다.
- 서버 OCR/API 키/외부 AI 업로드가 없습니다. 모델과 엔진도 같은 Vercel 사이트에서 제공합니다. 사진과 결과는 메모리에 머무르며 새로고침하면 사라지므로 작업 파일로 저장해야 합니다.
- HWPX는 ZIP 기반의 실제 한글 문서입니다. 본문은 텍스트, 보기는 네이티브 표, 그림은 PNG/JPEG, 문제 번호는 선택적으로 미주입니다. A4 1단·2단, 9–12pt를 지원합니다. 바이너리 `.hwp`를 생성하거나 확장자만 바꾸지 않습니다.
- 낮은 해상도, 기울어짐, 검은 필기, 수식·분수·동그라미 선지에는 오인식과 누락이 생길 수 있습니다. 원본 확인이 필요하며 OCR 신뢰도는 정확도 보증이 아닙니다.
- 그림을 자동으로 찾아 분리하거나 시험지 배치를 그대로 복제하지 않습니다. 그림 영역을 직접 지정하고 최종 쪽 배치는 한글에서 확인합니다.
- HWPX의 ZIP/XML/참조 무결성, 표·그림·미주 생성은 테스트합니다. 실제 한컴 한글의 화면 렌더링은 이 환경에서 검증하지 못했습니다.
- 공개 예제는 코드로 만든 과학 연습 문제이며 사용자가 제공한 사진이나 문서 본문을 배포하지 않습니다.

## 개발·배포

저장소 루트에서 Node.js 24, npm을 사용합니다.

```sh
npm ci
npm test
npm run dev
npm run build
```

`vercel.json`은 `npm run build`를 실행하고 `dist`를 배포합니다. 빌드에서 기존 `index.html`, `newpage.html`, `backup`을 복사하고 `/ocr/` 앱을 추가합니다. 모델/엔진은 고정된 npm 의존성에서 복사하므로 큰 바이너리를 Git에 커밋하지 않습니다. 운영 환경 변수는 필요 없습니다.

## 코드

- `web/app.js`: 사진, 영역 선택, 결과 편집, 작업 저장과 복원
- `web/ocr.js`: 전처리와 OCR 워커, 취소, 블록 읽기 순서
- `web/hwpx.js`: 편집 가능한 HWPX 생성
- `web/template.json`: 개인 정보와 문서 본문이 제거된 한글 서식 정의
- `tests/structure.mjs`: 취소, 읽기 순서, 표·그림·미주와 XML 문자열 회귀 검증
