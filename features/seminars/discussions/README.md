# Seminar Discussions

이 디렉터리는 세미나의 공통 규약과 주제별 의도를 논의하는 영구 작업
공간이다. 확정되지 않은 제안을 실행 데이터와 분리해, 무엇을 왜 바꾸는지
먼저 합의할 수 있게 한다.

## Boundary

- 이 문서들은 작성 입력이며 런타임에서 import하지 않는다.
- 공통 결정은 `../formats/`의 규약으로, 주제별 결정은
  `../data/topics/`의 구조화된 콘텐츠로 반영한다.
- 열린 질문은 합의 없이 화면 콘텐츠를 바꾸지 않는다.
- 실제 동작의 최종 근거는 형식 문서, 주제 데이터, 자동 테스트와 브라우저
  검증이다.

## Decision flow

```text
open question -> discussed decision -> formats/ or data/topics/ update -> tests -> browser check
```

1. `common.md` 또는 해당 `topics/*.md`의 `Open questions`에 질문을 적는다.
2. 근거, 예상 영향, 대안과 주요 trade-off를 함께 논의한다.
3. 합의한 내용은 `Decisions`에 옮기고 적용 대상을 명시한다.
4. 공통 규칙은 `formats/`, 주제 내용은 `data/topics/`에 반영한다.
5. 가까운 자동 테스트와 두 표현의 브라우저 검증으로 결과를 확인한다.

## Follow-up archive

현재 성공 기준에 필요하지 않은 문제와 개선안은 작업 범위를 즉시 넓히지
않는다. 관련 문서의 `Open questions`에 다음 정보를 남기고 `확인` 또는
`보류` 상태로 아카이빙한 뒤, 다음 작업 단계를 시작할 때 사용자와 먼저
검토한다.

- 관찰한 현상과 재현 또는 근거
- 독자, 발표자, 유지보수에 미치는 영향
- 제안과 대안
- 현재 작업에서 다루지 않는 이유

보안, 데이터 손실 또는 현재 작업을 막는 회귀는 후속 논의로 미루지 않고
즉시 다룬다. 채택되지 않은 항목도 삭제하지 말고 보류 또는 기각 이유를
남긴다.
