# Manual seminar PDF handoff

This directory reserves four future static assets:

- `python-intro-reading.pdf` — portrait
- `python-intro-slides.pdf` — landscape
- `web-intro-reading.pdf` — portrait
- `web-intro-slides.pdf` — landscape

The user manually prints each PDF from the corresponding visible HTML view and
visually reviews its orientation, content, page breaks, clipping, and legibility.
The repository publishes no download link while its matching file is absent.

A later task may add ordinary `<a download>` links only after it verifies all
four files exist, each file has a PDF signature, and each browser download
returns the intended file. This directory currently contains no PDF binaries.
