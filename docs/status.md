## 세미나 작성 시스템

세미나 전용 데이터, UI, 레이아웃, 에셋, 스타일과 테스트는
`features/seminars/`가 소유하고 `pages/`에는 기존 URL 진입과 초기 조립만
남긴다. `introductory-60`의 구조화 원본에서 발표용 가로 슬라이드와
독립적으로 읽히는 세로 문서를 만든다.

런타임 PDF 생성, 외부 CDN, 팝업·인쇄 fallback과 다운로드 컨트롤은
제거했다. 두 HTML 화면과 수동 브라우저 인쇄용 CSS는 유지한다. 향후
PDF 공개 계약은 `features/seminars/assets/pdf/README.md`가 소유한다.
