## 세미나 작성 시스템 준비

확정된 목표는 모든 세미나가 대상 독자, 목적, 핵심 메시지, 전체 맥락과 세부 내용을 구조적으로 표현하는 공통 작성 계약을 갖는 것이다. 제목, 본문, 목록, 코드, 인용, 요약과 이미지를 명시적 콘텐츠 블록으로 다루고, 저장소가 소유하는 이미지에는 최소한 경로와 대체 텍스트를 둔다. 레이아웃별 콘텐츠 예산과 실제 DOM overflow를 함께 검증하며 같은 구조화 콘텐츠에서 발표 화면, 읽기 문서, PDF 또는 인쇄 결과물을 만든다.

다음 설계에서 확정할 항목은 다음과 같다.

1. 발표 슬라이드와 읽기 문서가 공통 원본을 공유하는 방식
2. 세미나 한 개의 디렉터리·파일 구성과 지원할 콘텐츠 블록
3. 레이아웃별 콘텐츠 예산과 경고·오류의 정확한 경계
4. 이미지 필수 메타데이터, 비율, 해상도와 출처 정책
5. 브라우저 런타임 조립을 유지할지 정적 산출물 생성 단계를 도입할지 여부
6. `python-intro`와 `web-intro`의 호환 마이그레이션 방식
