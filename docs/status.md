# Project Status

## 진행 중

- Vercel 로컬 개발 환경을 포함한 구조 개편 설계 갱신

## 확인된 문제

- 슬라이드 헤더가 연결 후 설정된 속성을 다시 렌더링하지 않는다.
- 가로 PDF 임시 DOM에 `.slide-container.horizontal` 구조가 없다.
- PDF 생성 실패 시 임시 DOM이 남을 수 있다.
- PowerShell 구조 검증 스크립트가 삭제된 CSS 경로를 요구하며 현재 환경에는 PowerShell 실행기도 없다.
- 세미나 안내의 Markdown 강조 문법이 HTML에서 그대로 노출된다.
- PDF 다운로드 버튼의 접근성 이름이 주제와 문서 형식을 구분하지 못한다.
- 페이지, 컴포넌트, 콘텐츠와 CSS의 책임 경계가 디렉터리에 일관되게 반영되지 않았다.
